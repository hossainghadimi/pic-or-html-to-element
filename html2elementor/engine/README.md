# Engine CPU

این پوشه برای موتور CPU است.

**دانلود:**
https://github.com/ggml-org/llama.cpp/releases/download/b11095/llama-b11095-bin-win-cpu-x64.zip (18.5 MB)

استخراج کنید و `llama-server.exe` و `mtmd.dll` را اینجا قرار دهید.

این موتور برای حالت فقط CPU است. برای حالت ترکیبی CPU+GPU، موتور CUDA را در `engine-cuda/` و DLLها را در `cuda/` قرار دهید.
